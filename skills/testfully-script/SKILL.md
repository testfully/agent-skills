# Testfully Script Skill

A comprehensive skill for writing Javacript code that utilises Testfully's built-in scripting capabilities to automate tasks and processes as part of Before Request and After Response script hooks in Testfully.

## When to Apply

Use and reference this skill and guidelines when:

- Writing or refactoring Javascript code to be used in Testfully's Before Request and After Response script hooks.
- Extend Testfully's features and capabilities beyond what is available through the UI by leveraging custom scripts.
