# Version Output

Use the version option to check which Testfully CLI version is installed.

## Command Form

```bash
testfully --version
```

## Arguments

### `--version`

Optional global boolean flag. Prints the installed Testfully CLI version and
exits. Example: `testfully --version`.

### Positional arguments

Not supported for version output. Run `testfully --version` without input files
or other positional arguments.
